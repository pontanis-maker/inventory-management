Factory Inventory Management System

A demo full-stack application: a Vue 3 single-page dashboard served by Vite, talking over REST to a FastAPI service that holds all data in memory, loaded at startup from JSON files. There is no database.

Data flow

  1. StartupOn import, mock_data.py reads each JSON file in server/data/ into Python lists and dicts that live for the process lifetime.
  2. User sets filtersThe FilterBar updates the shared refs in useFilters (period, warehouse, category, order status). Every view reads the same state.
  3. View requests dataThe view calls a method in api.js, which drops "all" values and sends the rest as query params (period becomes month).
  4. FastAPI filters in memoryThe route handler applies apply_filters / filter_by_month over the in-memory lists and computes any aggregates.
  5. Pydantic validates the responseThe response_model serializes and validates the result before returning JSON.
  6. View rendersRaw responses are stored in refs (allOrders, inventoryItems); charts and tables read from computed properties derived from them.

Conventions and caveats

Things worth knowing when reading the code
  • Inventory filters ignore month: inventory data has no time dimension.
  • api.js calls /api/tasks and /api/purchase-orders, but no such routes exist in server/main.py. Those calls (and the CreatePurchaseOrderRequest model) currently have no working backend.
  • Backlog.vue exists but is not registered in the router in main.js.
  • The API base URL is hard-coded to http://localhost:8001/api in api.js.
  • Revenue goals: $800K per month for a single month, $9.6M year to date for all months.
  • Design system: slate/gray palette, green/blue/yellow/red for status, custom SVG charts, no emojis in the UI.
